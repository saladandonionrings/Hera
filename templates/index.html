GHunt (Google Identity)

The Google Identity module needs a GHunt session on the server. Install the GHunt Companion browser extension, export your logged-in Google session as base64, then paste it below.

This runs ghunt login directly on the server, replacing any existing session. Anyone with access to this page can trigger it — keep this deployment private.

Telegram (Phone module)

Optional — enables the Telegram registration check on phone number scans. Create your own API app at my.telegram.org/apps, then log in below — Hera saves the API ID/Hash to .env automatically, no manual step needed.

This creates a Telegram user session on the server (via Telethon), saved as a .session file and reused for every scan afterwards. Only needs to be done once.
